# chromeext

Larry's Chrome extensions, one per folder. Each is loaded unpacked from
`chrome://extensions` (Developer mode on, then **Load unpacked** and pick the
extension's folder).

| Folder | What it does |
| --- | --- |
| [youtube-old-layout](youtube-old-layout/) | Restores the classic YouTube watch page (recommendations on the right, comments under the video) by pinning YouTube's layout experiment flags to false. |
