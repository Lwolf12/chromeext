# chromeext

Small Chrome extensions, one per folder. None of them are on the Chrome Web
Store; you load them straight from this repository.

| Extension | What it does |
| --- | --- |
| [youtube-old-layout](youtube-old-layout/) | Brings back the classic YouTube watch page: recommended videos on the right, comments under the video. |

## Installing any of them

1. Click the green **Code** button at the top of this page and choose
   **Download ZIP**, then extract the ZIP somewhere you'll keep it (Chrome
   loads the extension from that folder every time it starts, so don't
   delete it afterwards).
2. In Chrome, open `chrome://extensions`.
3. Turn on **Developer mode** (toggle in the top right).
4. Click **Load unpacked** and pick the extension's folder, for example
   `chromeext-main/youtube-old-layout`.

To update later, download the ZIP again, replace the folder, and click the
reload icon on the extension's card in `chrome://extensions`.
